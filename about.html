Mục tiêu của Lab 1

  • Hiểu vòng đời DevOps: Plan → Code → Build → Test → Release → Deploy → Operate → Monitor

  • Viết pipeline GitHub Actions để tự động deploy lên GitHub Pages
  • So sánh quy trình deploy thủ công với quy trình CI/CD

Kết quả đạt được

  • Mỗi lần git push lên nhánh main, pipeline tự build và deploy trong khoảng 9 giây
  • Tìm và sửa được lỗi 403 Permission denied bằng cách thêm permissions: contents: write vào deploy.yml
